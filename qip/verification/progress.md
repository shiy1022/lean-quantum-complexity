## Design decisions recorded for later tasks

- **Wire layout (Q13).** Private wires come first (`0 … priv-1`, output `out < priv`). Each
  message then gets a fresh register of its own width, in order. Block `j` runs before message
  `j`. During block `j` the verifier holds every received prover→verifier register `k < j` and
  every unsent verifier→prover register `k ≥ j` (initially `|0⟩`). Q15's execution semantics and
  Q29's fixed-register normal form must follow this convention.
- **Schedules.** `QIPm k` should use `HasSchedule k`: exactly `k` alternating messages, the last
  to the verifier. `stdSchedule 3 = [P→V, V→P, P→V]`.
- **Encoding.** Unary naturals and gate tags 0–4 follow `ShiBQP.encNat`/`encInstr`, so the
  Q34 printers can reuse the proved unary parsers. `encode_length` makes the serialized size an
  exact, closed-form resource.
- **Constants (Q33).** Bell-test soundness is `35/36 = 1 - 1/36`. Padding goes to
  `padCount m ≤ 2m + 3`, of the form `2^(r+1)+1`. With `δ = 1/(36 M²)` and `K = 72 M²`,
  `soundness_schedule` composes these with `r` halvings.
- **Halving layout (decided at Q29).** With `M = 2n + 1` messages (`n = 2^r`, `r ≥ 1`), cut after
  block `c = n + 1`. The forward half is messages `c, …, 2n`; the backward half undoes blocks
  `c, …, 1` with messages `c - 1, …, 1` reversed (undoing turn `0` is not needed: it does not
  touch the wires held during block `0`). Both halves have `n` messages; with the midpoint
  message the result has `n + 1 = 2^(r-1)·2 + 1` messages. Halved message `k ≥ 1` carries original
  message `c + k - 1` (forward) or `c - k` (backward), so it needs the larger of the two widths;
  a uniform-width normal form is therefore not needed (and would not survive one halving).
- **Halving soundness plan (Q30–Q31, recorded before implementation).** Work in the pure-run
  model. (1) Every isometric prover has a *unitary* prover on one fixed memory `N = Σ k, M k` with
  the same runs (unitary extension via `exists_unitary_of_mul_conjTranspose_eq`). (2) Halved
  verifier: private working copy of all wires of `d`, coin, output; message `0'` is the cut state;
  each block swaps the arriving message into the working copy, applies a block of `d` (forward,
  coin `0`) or an inverse block (backward, coin `1`), and swaps the outgoing register out; all
  branch-dependent gates are controlled on the private coin, whose public copy rides on message
  `1'`. (3) For a fixed unitary prover, the forward branch accepts `ξ` with probability
