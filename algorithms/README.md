# Quantum algorithms: faithful statements

Lean 4 statements of the results in the **algorithms** field of the
[prove2quantum](https://github.com/shiy1022/prove2quantum) dependency map: de Wolf's
*Quantum Computing: Lecture Notes* and Childs's *Lecture Notes on Quantum Algorithms*. The ten
nodes that the map marks as cited results with imported proofs are not stated here.

**Status: statements only.** Every theorem body is `sorry`. A theorem here is a checked claim
about *what the source says*, not a proof. Definitions under `QAlgorithms.Defs` contain no `sorry`.

| Path | Contents |
|---|---|
| `QAlgorithms/Defs/` | Shared definitions (states, circuits, oracles, query complexity, ...). Drafted once, reviewed blind and against the page, then frozen by sha256 |
| `QAlgorithms/DeWolf/ChNN.lean` | Statements from de Wolf chapter NN |
| `QAlgorithms/Childs/ChNN.lean` | Statements from Childs chapter NN |
| `QAlgorithms.lean` | Root module, regenerated by the pipeline |

Toolchain and Mathlib match the rest of this repository (Lean v4.33.1, Mathlib `0df444a3`).
`autoImplicit` is off.

The files are written by `prove2quantum/pipeline`. Each statement's source page, verbatim
quotation, blind read-back and moderation record are in that pipeline's run directory. Edit
statements through the pipeline, not by hand, so the read-backs stay matched to the Lean.

```bash
lake exe cache get
lake build
```
